# Era Accuracy: Haunted GeoCities

The costume must look like a real 1998 GeoCities page, using only what a 1998 GeoCities page had.

## Permitted 1998 Techniques

- **Tiled backgrounds** — repeat background images.
- **Marquees** — `<marquee>`-style scrolling text effects (CSS animation, not the deprecated tag).
- **Under-construction GIFs** — original pixel art drawn by us.
- **Hit counters** — odometer-style visitor counters.
- **Guestbook** — themed comment area.
- **Web rings** — "previous / next" ring navigation.
- **Fonts** — Comic Sans MS and Times New Roman.
- **Colour palette** — 216 web-safe colours only (`#00`–`#FF` in `33` steps per channel).
- **Pixel art** — all icons, sprites, and decorations are original pixel art.

## Constraints

- All assets are **original** — no third-party trademarks, logos, or copyrighted images.
- Effects should be implemented with modern CSS/Canvas but must *look* 1998-authentic.
- Avoid any visual element that did not exist on a typical GeoCities page circa 1998.
